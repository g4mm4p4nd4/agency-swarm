This guide covers the structural differences between example-based CLI usage
and the fork's `run_fastapi()` HTTP runtime.

## Why migrate

| Before (CLI) | After (FastAPI) |
|---|---|
| Single-process, runs once | Multi-request, persistent server |
| Threads die with process | Thread persistence via agency factory |
| No auth | Bearer token support |
| No CORS | Configurable CORS |
| Manual server setup | Built-in uvicorn orchestration |
| No streaming for remote clients | SSE streaming endpoint |
| No cancel/control plane | Cancel endpoint for active runs |

## Step-by-step migration

### Step 1: Wrap agency creation in a factory

**Before** (CLI pattern):

```python
from agency_swarm import Agency, Agent

agent = Agent(name="Assistant", instructions="...")
agency = Agency(agent)
```

**After** (FastAPI factory pattern):

```python
from agency_swarm import Agency, Agent

def create_agency(load_threads_callback=None):
    return Agency(agent, load_threads_callback=load_threads_callback)

app = run_fastapi(
    agencies={"my-agency": create_agency},
    return_app=True,
)
```

The factory pattern ensures each HTTP request gets a fresh agency instance
preloaded with conversation history.

### Step 2: Replace asyncio.run with run_fastapi

**Before** (CLI pattern):

```python
async def main():
    async for event in agency.get_response_stream("Hello"):
        if hasattr(event, "data") and getattr(event.data, "type", None) == "response.output_text.delta":
            print(event.data.delta, end="")

asyncio.run(main())
```

**After** (FastAPI pattern):

```python
from agency_swarm import run_fastapi

run_fastapi(
    agencies={"my-agency": create_agency},
    port=8080,
)
```

Your client code becomes an HTTP request instead of a direct agent call:

```python
import requests

response = requests.post(
    "http://localhost:8080/my-agency/get_response",
    json={"message": "Hello"},
)
```

### Step 3: Add authentication

**Before**: No auth.

**After**:

```python
# .env
APP_TOKEN=your-secret-token-here
```

```python
run_fastapi(
    agencies={"my-agency": create_agency},
    app_token_env="APP_TOKEN",
)
```

Client adds the header:

```python
headers = {"Authorization": "Bearer your-secret-token-here"}
```

When `APP_TOKEN` env var is unset, auth is automatically disabled
(development-only mode).

### Step 4: Configure CORS

**Before**: No CORS.

**After**:

```python
run_fastapi(
    agencies={"my-agency": create_agency},
    cors_origins=["https://my-frontend.com"],
)
```

When `cors_origins=["*"]` (the default), `allow_credentials` is
automatically disabled for browser security compliance.

### Step 5: Handle streaming

The FastAPI streaming endpoint uses SSE (Server-Sent Events) over HTTP
instead of the async generator pattern:

```python
import json
import requests

with requests.post(
    "http://localhost:8080/my-agency/get_response_stream",
    json={"message": "Hello"},
    stream=True,
) as r:
    for line in r.iter_lines():
        if line.startswith(b"data: "):
            payload = json.loads(line[6:])
            # handle event
```

### Step 6: Add logging (optional)

```python
run_fastapi(
    agencies={"my-agency": create_agency},
    enable_logging=True,
    logs_dir="activity-logs",
)
```

Exposes `POST /get_logs` with request body `{"run_id": "..."}`.

## Complete migration example

### Before (CLI)

```python
import asyncio
from agency_swarm import Agency, Agent, function_tool

@function_tool
def get_weather(location: str) -> str:
    return f"Weather in {location}: sunny, 22C"

ceo = Agent(
    name="CEO",
    instructions="Delegate weather queries.",
)
worker = Agent(
    name="Worker",
    instructions="Use get_weather for weather queries.",
    tools=[get_weather],
)

agency = Agency(
    ceo,
    communication_flows=[ceo > worker],
)

async def main():
    async for event in agency.get_response_stream("What's the weather in London?"):
        if hasattr(event, "data") and getattr(event.data, "type", None) == "response.output_text.delta":
            print(event.data.delta, end="")

asyncio.run(main())
```

### After (FastAPI)

```python
import os
import sys

sys.path.insert(0, os.path.abspath(os.path.join(os.path.dirname(__file__), "..", "src")))

from agency_swarm import Agency, Agent, function_tool, run_fastapi

@function_tool
def get_weather(location: str) -> str:
    return f"Weather in {location}: sunny, 22C"

ceo = Agent(
    name="CEO",
    instructions="Delegate weather queries.",
)
worker = Agent(
    name="Worker",
    instructions="Use get_weather for weather queries.",
    tools=[get_weather],
)


def create_agency(load_threads_callback=None):
    return Agency(
        ceo,
        communication_flows=[ceo > worker],
        load_threads_callback=load_threads_callback,
    )


if __name__ == "__main__":
    run_fastapi(
        agencies={"weather-agency": create_agency},
        port=8080,
    )
```

## Deployment checklist

- [ ] Wrap agency creation in a factory function
- [ ] Set `APP_TOKEN` or disable auth for dev (default disabled)
- [ ] Configure `cors_origins` for your frontend domain
- [ ] Enable logging for production debugging
- [ ] Pin uvicorn >= 0.33 for websocket-sansio support
- [ ] Use single-worker deployment (cancel registry is in-memory)
- [ ] Set `allowed_local_file_dirs` if serving local files
- [ ] Add health check endpoint (e.g., `@app.get("/health")`)
